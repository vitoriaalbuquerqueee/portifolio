## 📌 Sobre o Projeto

Este projeto consiste na construção da estrutura HTML do meu **Portfólio Pessoal**, criado com o objetivo de apresentar minhas competências técnicas, projetos desenvolvidos e fornecer um canal direto de contato. 

A aplicação conta com uma navegação responsiva, estrutura semântica para acessibilidade e SEO, integração com o carrossel de projetos via Swiper.js, além de uma página dedicada de confirmação de envio de mensagem (`success.html`).

---

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica da aplicação.
- **CSS3**: Estilização e responsividade *(em desenvolvimento)*.
- **Swiper.js**: Biblioteca para o carrossel de exibição de projetos.
- **Git & GitHub**: Controle de versão e hospedagem do código.

---

## 📁 Estrutura das Páginas

- **`index.html`**: Página principal contendo as seções:
  - **Header**: Logo e menu de navegação.
  - **Hero (`#hero`)**: Apresentação inicial e call-to-action.
  - **Sobre mim (`#about`)**: Resumo profissional e métricas do GitHub.
  - **Projetos (`#projects`)**: Carrossel interativo com os cards de projetos.
  - **Contato (`#contact`)**: Redes sociais e formulário para envio de mensagens.
  - **Footer**: Direitos autorais e créditos.

- **`success.html`**: Página de confirmação exibida após o envio do formulário de contato, garantindo feedback imediato e navegação de retorno à página principal.

### Opção 2: Gerar o arquivo PDF a partir do Markdown no VS Code

Para converter o arquivo `README.md` em **PDF**:

1. No VS Code, vá na aba de extensões (`Ctrl + Shift + X` ou `Cmd + Shift + X` no Mac).
2. Busque e instale a extensão **Markdown PDF** (por *yzane* ou *yyuu*).
3. Abra o seu arquivo `README.md`.
4. Clique com o botão direito em qualquer lugar do texto do arquivo e selecione:
   **Markdown PDF: Export (pdf)**.
